VoltCargo font files currently used by the app:

- `CamptonMedium.otf` for body text
- `CamptonSemiBold.otf` for heavier body text

If production `.woff2` versions are available later, use them because they are smaller and load faster in browsers.

The app uses:

- Headings/primary display: Newake
- Buttons: Newake
- Body text: Campton
